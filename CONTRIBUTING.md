# Contributing

Read PRD.md and AGENTS.md. Use a focused branch and link a story/issue. Add meaningful validation for behavioral changes, record source versions and licenses, update the relevant docs and run make check. Keep generated progress files current. Never attach credentials, private prompts, source tarballs, disks, models or ISO binaries to Git. Record hardware support only after testing exact hardware. The repository is private during initial development; a public contribution process will be finalized before opening it.
