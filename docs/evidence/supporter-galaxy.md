# Floating supporter galaxy — 2026-11-07

Replaced rectangular name cards with text-only stars: continuous gentle drift,
local CSS perspective, restrained extruded text shadows and a warm selected state.
The real and 100-name demo walls use the same generator and single community JSON.
No donor ranking or additional personal data is introduced.

A new built-in-generated, transparent happy Toddy expression is used as ONE fixed
portrait for this page. It is not swapped with any other image when selecting
names. The head follows the selected position through interpolated CSS 3D
transforms; pupils are not independently rigged. A vector constellation line and
localized live caption connect the interaction. Escape clears selection and native
buttons support keyboard/touch. Original logo/mascot bytes remain unchanged.
The new expression and full prompt/reference/hash are recorded in brand metadata.

Two small inline-SVG bone meteors cross the background at different intervals,
with continuous light trails. Ambient stars, orbit markers and portrait breathing
use CSS. Offscreen names/galaxy and hidden-document animations pause. No particle
engine, external library, frame sequence, canvas loop or persistent RAF loop is
used. Reduced motion removes drift, head orientation, meteor and orbit animation;
selection and its text feedback remain available.

## Basic browser verification

- Both walls, six languages and 320/390/768/1440 widths: 48 combinations without
  horizontal document overflow.
- Inspected desktop, selected name, mobile and bone-meteor screenshots under
  /tmp/toddy-galaxy-*.png. Corrected a mobile overlap by moving perspective from
  the entire long list to individual names.
- Corrected touch hit-testing by keeping decorative depth above the local plane.
  Native touch then selected names 1, 50 and 100 with no page errors or overflow.
- Keyboard Enter selects, Escape resets; reduced motion reports no name animation,
  no head transform and hidden meteors. Portrait src remains identical throughout.
- Head samples at 100 ms intervals showed five distinct intermediate matrices
  after selecting a different position, rather than an abrupt pose change.
- Of 100 names, only seven had running drift animations in a sampled mobile view;
  offscreen names paused. This is functional evidence, not a hardware FPS guarantee.
- Existing project/export tests and JS syntax checks pass. Foundation ISO and
  guest phase state are unchanged.
