## B01-B: Native unprivileged build namespace

[Actual probe](B01-build-isolation.json) compiled and ran a native C program in
staging as UID/GID 101. Effective/permitted capabilities were zero, no-new-privileges
was set, /usr, /src, /etc and /run writes were rejected read-only. Guest /root,
/sources and D-Bus sockets were absent. A private network namespace rejected
external connection with ENETUNREACH. Only build/stage/tmp were writable.
Postchecks found no outside marker on the target; namespace mounts disappeared
and the exclusive build lock was released.

First attempt failed before executing native code: dropping setuid/setgid from
the capability bounding set prevented chroot from setting supplemental groups.
The namespace cleanup also retained its cwd inside a mount. Corrected by retaining
only chroot/setuid/setgid for entry (actual native process has zero capabilities)
and leaving that cwd before cleanup. One corrective attempt passed. Original log
is preserved locally as isolation-probe-1.log; failure budget remains recorded.

This qualifies the compile namespace, not a narrow package-transaction optimization.
Escaping staged links/collisions, maintainer side effects and transaction/recovery
coverage still need owning checks. Unqualified native installations retain full
root before/after verification. The selected BLFS 13.1-systemd GLib 2.88.3 bootstrap
is now compiling/staging in this namespace with fallback downloads disabled;
its successful runtime result is not assumed.
