## Reproduction and negative checks

```sh
python3 scripts/fetch_books.py
python3 scripts/fetch_sources.py
python3 -m unittest discover -s tests -v
make check
```

Book extraction runs only after its frozen SHA-256 passes. Source retrieval
never extracts archives; future recipes must repeat integrity verification
before extraction. Negative tests corrupt cached bytes and alter SHA-256
pins, verifying both fail. Unsafe source filenames are rejected. Planning
validation requires a verified source lock and valid hashes when H02 is
completed. A failed run cannot label an incomplete set verified.

BLFS application sources will be frozen individually before their relevant
recipes; the entire optional BLFS package universe is not downloaded here.
