actual source-built target and a disposable guest. H11/H12 release acceptance
and physical hardware support are not claimed.

  stages. Independent ownership, full-tree attribution, runtime availability and

  383 executable scripts. See H10-root-assembly.json and ADR-0099.

- Actual BIOS/CD QEMU boot reached the source-built login and Bash console.

Systemd reported its read-only lower loop still busy during final shutdown,
then powered off. No writable persistent disk was attached. Preserve this
qualification; complete initramfs teardown is not inferred from QEMU exit zero.

## Reproduction and recovery

Follow [BUILD.md](../BUILD.md) and [RECOVERY.md](../RECOVERY.md), the frozen
LFS/BLFS 13.1-systemd inputs, and ADR-0047/0048/0058/0072–0082/0096–0099.
The full driver invokes the same media-only continuation that revalidates the
accepted compression before generating protected nested media output. Per-stage
reports and failed generations remain outside Git with hashes in the linked
JSON evidence. Source packages were not rebuilt to recover image-only defects.

The initial baseline transfer, Info null-device, runtime path classification and
media-parent failures remain failed in their preserved logs. Their corrections
have now passed complete positive integration. Native media dependencies and
the libisoburn CLI correction have separate accepted evidence. The original
failed/cancelled Berkeley DB full suites remain unchanged under ADR-0092.
