## Preflight failures and bounded recovery

The new read-only qualifier first wrongly assumed every preparation edit had a
patch digest. The final entry is instead the explicit frozen-book DB2 exclusion.
Correction1 then incorrectly depended on guest documentation, which is excluded
from the verified metadata transfer. Correction2 passed the pinned input/patch
checks but assumed the original command used a scratch-suffixed script; actual
receipt shows `/src/toddy-build.sh`. No promotion/package/install occurred during
these failed read-only preflights. The two failed corrections were parked in the
persistent ledger while independent CUPS resolver/local-test work advanced.

The actual original command vector was captured read-only and qualified by three
host tests, including changed input/worker/recipe refusal. One logged bounded
full-qualifier extension passed, then the distinct first native transaction
completed. Historical budgets remain retained. Never replay the accepted install,
scratch preparation, metadata4, compiler, original tests or source extraction.

## CUPS local tests and remote diagnostic classification

[Actual resolver qualification](../evidence/B02-cups-resolver-qualified.json)
passed in the real compiler namespace: exact private hosts, UID101, capabilities0,
NoNewPrivs and hostname resolution. Guest and target hosts hashes unchanged.
This qualified a single logged bounded finish4 extension after independent MIT

[Actual finish4](../evidence/B02-cups-local-tests-checkpoint.json) preserved the
compiler and reused completed array/file evidence; i18n/IPP/HTTP/options/PWG/
raster/PPD local results were0. The last selected `testsnmp` command returned1:
its source requires a remote host/IP; no arguments print the default-community
check then usage. It is a remote SNMP diagnostic, not an automatic no-argument
unit test. No remote query was attempted, and this is not an SNMP test pass.

The extension stopped before staging, preserving all results and the exact
failed SNMP command/log. CUPS remains parked; do not rerun the nine successful
programs. A future source-backed bounded staging-only recovery must retain this
failed result separately, require the exact nine local results and qualify the
SNMP usage classification independently. Recheck resource margins before any
mutation; the newly installed MIT payload leaves little target headroom.
