# Experimental preinstalled assistant MVP

The explicit `phase2-mvp-preinstalled-v1` delivery class is an owner-authorized
preview with `g2_eligible: false` and `automatic_activation: false`. It is separate
from the standard offline/base profile and does not complete B13/G2. Preserve
historical foundation evidence and disclose pending physical validation, known
bugs and untested paths. Full original G2/native acquisition acceptance remains
pending; preinstallation is not an acquisition test.

The coordinator runs the existing `image_projection.py --mvp` on the designated
builder, consuming `config/phase2/mvp-desktop-runtime-roots.json`. Its fixed fresh
output is `/sources/stage/toddy-mvp-image-projection-1`. The standard command and
profile are unchanged. The input/assembly coordinator uses distinct MVP slots;
never relabel a standard generation or reuse an uncertain write generation.

This profile requires actual native archive-backed agent/executor, Node, llama,
voice controller/engines/multilingual speech model/catalog, PipeWire audio tools
and integrations. All existing package records, signatures, dependency closure,
source/legal provenance, generated configuration, finalizer, recovery and space
checks still apply. No current-root copy or stub component is accepted. Installed
payload readback revalidates the hash-bound explicit profile and preview markers.
Updating the packaged payload verifier requires a fresh installer package attempt;
it does not require rebuilding Qt or Calamares.

Preinstalled software provides availability, not permission: the owner explicitly
chooses API/local configuration, credentials, microphone, integrations and
privileged grants through the existing product flows. No provider account or
hosted service is mandatory. Acquisition is still available for later updates.

No Qwen weights are packaged or activated. A local model requires the owner's
license approval and existing reviewed model import/binding flow, including an
owner-owned regular file with mode `0600` and the frozen supported hash. The
coordinator's cached Qwen is qualification data only. API configuration is the
other MVP path; the supplied multilingual voice model is a separate speech asset.

Basic source tests exercise the explicit class and real signed tiny fixture
archives, not native boot acceptance. Actual MVP installation/boot/UI/Stop/auth
results must be recorded separately before delivery, with their measured scope.
