# Website-only Toddy expressions

The owner requested a bored yawn on hover, ten short personality comments and a
public creator-profile link. These two transparent 1254x1254 PNGs are expression
keyframes generated from the approved mascot using the built-in image tool:

- toddy-yawn-half.png: heavy eyelids, opening mouth.
- toddy-yawn-full.png: closed eyes and the peak of a relaxed yawn.

The protected [original mascot](../toddy-os-system-icon.png) remains the idle
frame, byte-identical. These generated expression variants are not replacements
for the OS identity, installer, screenshots, wallpapers, logo or system icon.
Full prompts, reference paths and output hashes are in the parent brand metadata.

Only the public website uses them. It downloads the extra frames after interaction,
plays one short yawn, returns to the original, and ignores overlapping triggers.
Reduced-motion preference retains the original still image while comments remain
available. A failed image decode also falls back to the static identity.

Original Toddy artwork and these variants: Marcos Araujo / Toddy OS,
[CC BY 4.0](../../../LICENSES/CC-BY-4.0.txt), with this modification notice retained.

`toddy-happy.png` is an additional generated happy
expression for the supporter galaxy. It is displayed as one fixed portrait, not
alternated with other frames. Head orientation and breathing are continuous CSS
transforms, with a vector constellation line toward the selected name. The
original logo remains unchanged. Prompt/reference/hash: parent brand metadata.
