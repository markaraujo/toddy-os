# Licensing and redistribution plan

The owner requires an open-source runtime path and future community distribution. Licensing of original repository code/docs/art is not finalized in this bootstrap; do not infer a license grant from the proposed policy. Resolve D10 before the first public source or binary release. The working proposal is MIT for original project code and CC BY 4.0 for original documentation/art where applicable.

Linux, GNU components, libraries, firmware, model weights, speech voices and reused third-party code retain their own licenses. Maintain a machine-readable component/license inventory, required notices and corresponding-source/build information as applicable. Review actual artifacts and dependencies before redistribution. Optional hosted API integrations must not be required to boot or use the local open path. Do not describe an open-source engine's arbitrary downloaded model as open-source without checking that model's terms.

Approved artwork was generated with the built-in image tool, not Higgsfield. Preserve generation provenance; web references informed the brief and were not copied into the artwork. No photograph of the actual dog was supplied. Production trademark/identity checks remain separate from technical development.
