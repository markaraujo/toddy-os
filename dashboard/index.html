DESIGN CONCEPT

These are design mockups. The ISO available today is the command-line foundation; it does not include these screens.

01 — KEEP IT FAMILIAR

Start with the essentials.

The plan keeps GNOME, everyday apps and Git in the base. Docker, OpenCode, VS Code and other extras will be optional, once their installation has been verified.

02 — MAKE IT YOURS

An assistant you can change.

After installing the assistant, choose a compatible local model or your own API provider. Edit Toddy's instructions, personality and skills; permissions are managed separately.

03 — STAY IN CONTROL

See what Toddy is doing.

Follow tasks and request Stop. Some writes must finish safely; canceling is not an undo. Administrative access will use separate, revocable permissions.

These features are planned for Phase 2 and are not in the current ISO.

02 / A proper welcome

During installation,
you'll have a choice.

Install the basic desktop offline. At the end, save your optional app choices; review and install them after signing in. You can add the assistant later, without reinstalling.

Technical acceptance criteria (English)
