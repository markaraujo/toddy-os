## Commit-sized execution slices

and regenerate progress. Each numbered slice can produce several small commits;
commit a working boundary without waiting for the entire story. Keep each diff
focused and save next command/log/checkpoint before stopping.

1. Implement a GTK4/Libadwaita main app and compact activatable text window, backed by the per-user service; keep model work outside GNOME Shell.
2. Register a conflict-checked configurable shortcut and launcher. Treat exact overlay placement as optional; ordinary app activation is the fallback.

5. Apply the Toddy persona and navy design using supported styles, visible focus and EN/PT interaction; record a text-assistant preview after applicable smoke checks.

Additional harness slice: Expose profile create/clone/select and persona/model/tool/budget settings, advanced validated editing, secret-free import/export and restore/reset using the same CLI/service backend.
