# H10 — Assemble the live system

Phase: foundation · Weight: 8/100

Status and dependencies are authoritative in [status.json](../status.json).

## Goal

Assemble the live system. Deliver verified behavior consistent with [PRD.md](../PRD.md), not merely a successful command.

## Prerequisites

H09

## Execution steps

1. Inspect prerequisites and the actual target; mark in_progress.
2. Read the frozen primary sources relevant to this milestone and record versions.
3. Implement resumable, reviewable changes in the disposable target.
4. Exercise the acceptance checks below; record commands, outcomes and recovery.
5. Update journal, errors/ADRs and status; run make check before completing.

## Acceptance criteria

- [ ] Create initramfs, compressed root and writable live overlay without embedding host mounts.
- [ ] Demonstrate correct root discovery and volatile-write behavior in a guest.
- [ ] Document persistence limits, rescue access and boot failure diagnostics.
