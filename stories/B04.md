## Outcome

Deliver native tools and the revocable privileged executor. Deliver observable behavior in small reviewable slices.

## Prerequisites

## Commit-sized execution slices

Start from a verified checkpoint, mark in_progress only when implementation starts,
and regenerate progress. Each numbered slice can produce several small commits;
commit a working boundary without waiting for the entire story. Keep each diff
focused and save next command/log/checkpoint before stopping.

1. Implement structured user-level file/shell tools and privileged package/service/network/configuration operations through authenticated local IPC.
2. Validate caller identity, schema, target paths and owner policy at dispatch; separate the root executor from UI/model processes.
3. Provide session and standing full-administration grants with expiry/revocation and a non-secret audit trail.
4. Integrate native package ownership rather than unmanaged installation commands; document unrestricted-root limits honestly.
5. Test one allowed operation, wrong-user/invalid/revoked requests and one malicious document/tool-output escalation or dummy-secret transfer.

## Acceptance criteria

- [ ] Native tools use validated authenticated IPC; ordinary tasks run unprivileged and authorized administrative actions actually work.
- [ ] The owner can grant session/standing full administration, inspect actions and revoke future dispatch without granting root to the conversational service.
- [ ] Focused wrong-user, malformed-request, revocation and malicious-content checks pass; keys do not enter model context or audit exports.
